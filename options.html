URL rules

Give each group a name and list one URL wildcard per line. Start a line with # to disable it. The first matching line wins, reading groups from top to bottom.

Use * for any text, including slashes. A trailing /* also matches the root path. Queries and fragments are ignored. Use chrome-extension://*/* for all extension pages, or replace the host * with one extension's ID. Browser pages work too: brave://extensions/* or chrome://settings/*. The brave:// and chrome:// schemes match each other. Short forms like brave://* and chrome-extension://* match every host and path under that scheme.
